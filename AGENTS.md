# Aturan kerja proyek

- Jawab dalam bahasa Indonesia dengan penjelasan langsung.
- Baca PROJECT.md dan STATE.md sebelum bekerja; perbarui STATE.md setelah perubahan bermakna dan sebelum pergantian agent.
- Semua perintah terminal harus menggunakan folder proyek ini sebagai working directory.
- Kerjakan perubahan di proyek ini. Jangan membuat salinan STATE.md yang menjadi sumber konteks kedua.
- Gunakan .agents/skills/session-handoff/SKILL.md saat serah terima.
- Jangan simpan token, password, API key, atau data folder pengguna dalam Git.
- Uji rename hanya pada folder sementara buatan pengujian; jangan mengubah file milik pengguna untuk pengujian.
- Pertahankan server pada loopback, validasi token serta Origin, dan jangan menimpa file saat rename atau undo.
- Sebutkan pengujian yang benar-benar dilakukan, batasan, dan pekerjaan tersisa.
- Hindari dua agent mengedit file yang sama bersamaan.
