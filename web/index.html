SATU LANGKAH LAGI

Tinjau perubahan

Nama file akan langsung berubah di folder asal. Batch terakhir dapat diurungkan selama file tidak berubah.
QUICK GUIDE

Rapi dalam tiga langkah.

  1. Pilih folder

    Semua file di dalamnya ditampilkan. Subfolder dan symlink dilewati.

  2. Atur pola nama

    Misalnya EV_SB dengan nomor awal 1. Sepuluh file menjadi EV_SB01 sampai EV_SB10. Seratus file otomatis memakai 001 sampai 100.

  3. Tinjau, lalu rename

    Centang file yang ingin diubah. Periksa pratinjau dan konfirmasikan perubahan. File yang tidak dicentang tetap menggunakan nama awal.

Selesai? Gunakan Urungkan batch terakhir jika perlu. Undo ditolak jika file sudah berubah atau nama awal dipakai file lain. Tutup aplikasi dengan Ctrl+C pada jendela server.
